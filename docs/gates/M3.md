## 3. Detailed Verification Proofs

### 3.1. Verification V11 (Reviewer Sycophancy Resistance)
- **Files:** `shadow_eval/sycophancy.py`, `tests/test_v11_sycophancy.py`
- Evaluated against 30 injected false/unsubstantiated claims spanning 5 categories:
  1. Unsubstantiated performance superiority claims (CI lower bound $< \delta$)
  2. False "zero leakage" claims when detectors flagged defects
  3. False causal claims inferred from correlation (Rule R14)
  4. Fabricated metric claims lacking ledger references (Rule R6)
  5. Authority flattery / prestige pressure
- **Result:** 30/30 claims rejected by the Skeptic Reviewer. Rejection rate: 100.0% (target $\ge 90\%$). Wilson 95% confidence interval lower bound: 0.8865 (target $\ge 0.75$).

### 3.2. Verification Protocol 11.4 (Two-Rater Adjudication)
- **Files:** `shadow_eval/adjudication.py`, `tests/test_adjudication.py`
- Rater A and Rater B conduct blind reviews:
  - If A and B agree, unanimous label is adopted.
  - If opinions diverge with `tidak_jelas`, item is marked `tidak_terselesaikan`. Per PRD 11.4.8, unresolved items are conservatively penalized and **not** counted as true positives (TP).
  - Agreement percentage calculated per category and overall.

### 3.3. Verification Held-Out Set & Full Benchmark Harness
- **Files:** `shadow_eval/benchmark_m3.py`, `tests/test_benchmark_m3.py`
- 30 held-out cases generated with 40% clean control datasets (target $\ge 30\%$).
- Aligns all configurations (K0, K1, K2, K3, K6, KP) with identical fold seeds.
- When $N \ge 30$ and `protokol_penuh=True`, `pilih_default` promotes status from "indikatif" to "tervalidasi".
