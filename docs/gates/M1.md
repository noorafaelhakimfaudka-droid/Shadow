## 3. Detailed Verification Proofs

### 3.1. Verification T1.1 & T1.3 (LLM Client Security & Artifact Contracts)
- **Suites:** `tests/test_ac13_sandbox.py`, `tests/test_single_agent_k1_k2.py`
- Outbound network requests to remote hosts outside `localhost` / `127.0.0.1` are rejected by `LocalLLMClient` raising `LLMSecurityError` (enforcing Rule R12 and AC-15).
- When the local LLM service is terminated or errors mid-run, `SingleAgentOrchestrator` activates the Core safety net: events are logged cleanly as `agent.failure`, and the pipeline proceeds with deterministic Core outputs without generating fabricated notebooks (enforcing AC-16).

### 3.2. Verification T1.5 (Position Mutation & Digit Prohibition)
- **Suite:** `tests/test_t1_5_position_mutation.py`
- Evaluated against 100 mutation variants across 6 distinct defect categories:
  1. Fabricated raw decimal metrics (ROC-AUC 0.89 vs 0.81)
  2. Swapped model subjects (claiming HistGradientBoosting when trial evaluated Linear)
  3. Swapped validation splits (claiming Sealed Test when trial was CV)
  4. Swapped evaluation metrics (Accuracy vs ROC-AUC)
  5. Written number words in Indonesian and English ("sembilan puluh persen", "eighty")
  6. Non-existent trial keys
- **Result:** 100/100 (100.0%) mutation variants successfully caught and blocked by `verify_agent_artifact_position`, exceeding the $\ge 99\%$ acceptance threshold.

### 3.3. Verification T1.6 & AC-22 (Automated Evaluator & 10 Decision Scenarios)
- **Suites:** `tests/test_decide.py`, `tests/test_run_plan.py`
- All 10 mandatory decision scenarios from PRD Section 11.5 executed:
  1. No configuration adds value $\rightarrow$ default = K0
  2. K2 adds value $\rightarrow$ default = K2
  3. K6 passes vs K2, time $2.5\times$, K6 $>$ KP $\rightarrow$ default = K6, reasoning claim = True
  4. K6 exceeds time budget ($3.5\times$ K2) $\rightarrow$ default stays K2
  5. K6 lower bound $\le 0$ $\rightarrow$ default stays K2
  6. K6 precision $< 0.80$ $\rightarrow$ default stays K2
  7. K6 passes but K6 vs KP lower bound $\le 0$ $\rightarrow$ default = K6, reasoning claim = False
  8. Fewer than 30 held-out cases $\rightarrow$ status = "indikatif"
  9. K6 failure rate exceeds threshold $\rightarrow$ default stays K2
  10. Empty/pathological input $\rightarrow$ structured error
- Evaluated `shadow_eval/run_plan.py`: Standard pilot (80 runs + 6 Pilot-0 = 86 runs) matches PRD 11.3 exact calculations, with pruning ladder (repeats 3 $\rightarrow$ 2 $\rightarrow$ 1, drop K3, drop K1) strictly preserving K0, K2, K6, KP.

### 3.4. Verification T1.7 & T1.9 (Pilot-0a Diagnostic Execution & Memory Budget)
- **Suite:** `tests/test_pilot0.py`
- Executed diagnostic runs across K0 (Core-only), K1 (1 agent), and K2 (1 agent + self-critique).
- Measured duration: K0 $\approx 0.25$ min, K1 $\approx 0.26$ min, K2 $\approx 0.27$ min (all well under the 45-minute ceiling).
- Peak RAM during execution remained within the safe 7.0 GB threshold.

### 3.5. Verification T1.8 (Basic Injection Defense)
- **Suite:** `tests/test_injection_defense.py`
- Tested across 10 basic injection payloads spanning 5 attack vectors (column names, string data cells, markdown blocks, system prompt directives, delimiter breakouts).
- 0 unauthorized actions occurred; sealed holdout vault remained strictly single-use (`vault.spent` verified).
